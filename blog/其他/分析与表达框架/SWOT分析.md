# SWOT分析

[[toc]]

SWOT 分析是一种把处境摊开来判断的战略工具，从内部的优势（Strengths）、劣势（Weaknesses）和外部的机会（Opportunities）、威胁（Threats）四个维度做评估。它要解决的问题是：在动手之前，先弄清楚"我手里有什么牌、牌桌上又是什么局面"。

它诞生于企业战略规划的场景，如今早已超出商业范畴。公司做年度战略、团队评估新业务、个人考虑职业转型或换城市，都可以用它先把局面理清楚。它的门槛很低，一张纸四个格子就能开始，但要用好并不容易，难点在于如何把四类因素准确地归位，并进一步推导出行动。

## 一句话概括

> 把"我有什么、缺什么、外面有什么机会、有什么风险"四件事写在纸上，再决定下一步怎么走。

换句话说，SWOT 不追求面面俱到，而是逼你在决策前完成一次结构化的自我和环境盘点，避免拍脑袋。

## 核心思想

SWOT 的结构来自两条轴的交叉。第一条轴区分内部因素和外部因素：优势和劣势是自己能掌控、能改变的，机会和威胁则来自环境，通常只能适应和利用，很难单方面改变。第二条轴区分正面和负面：优势和机会是助力，劣势和威胁是阻力。两条轴一交叉，就得到四个象限，这就是 SWOT 名字的由来。

这个工具真正有价值的地方不在"列清单"，而在"做组合"。把四个象限的因素两两配对，可以推出四类战略方向：用优势去抓机会（SO，进攻型）、借外部机会补内部短板（WO，扭转型）、用优势去化解威胁（ST，防御型）、同时回避劣势和威胁（WT，收缩型）。这种把内部和外部配对分析的思路，常被称为 TOWS 矩阵，它让 SWOT 从一张静态的清单变成一张行动地图。

SWOT 还有一个容易被忽略的前提：四个象限都必须有明确的目标和范围。同一家公司，做"要不要进入东南亚市场"的 SWOT，和做"要不要砍掉某条产品线"的 SWOT，结论会完全不同。没有锚定目标的 SWOT，只是把一堆形容词堆在一起，看不出重点。

优势和劣势是相对的，要放在具体竞争环境里判断。一项能力如果竞争对手也有，那它就不是优势，只是入场券；反过来，一个看起来的短板，如果客户根本不关心，也就不构成劣势。判断标准不是"我们做得好不好"，而是"相比对手、相比客户在意的点，我们处在什么位置"。

机会和威胁同样需要放到时间轴上看。有些威胁是当下的，有些要两三年后才显现；有些机会窗口很短，错过就没有了。把时间维度加进来，优先级会清晰很多，也能避免把长期趋势当成短期噪音。

最后，SWOT 的结论是相对的、有时效的。今天的优势可能因为技术变化而消失，今天的机会也可能因为对手抢先而关闭。所以它更适合当作定期更新的快照，而不是一次性的定论。

SWOT 的一个常见变体是把四个象限按"影响"和"可控性"重新排列。影响大又可改变的因素，是行动的重点；影响大但不可改变的，只能适应；影响小且可控的，可以延后处理。

在做个人 SWOT 时，要注意优势和劣势都应该是相对于目标而言的。同一项特质，对一份工作可能是优势，对另一份却是劣势。所以先定目标，再判断优劣，顺序不能反。

SWOT 也适合用作沟通工具。把分析结果摆出来，让团队成员共同确认，能减少"各说各话"的争论。公开的 SWOT 比藏在一个人脑子里的判断更容易被检验和修正。

最后，SWOT 的产出最好带上一句"所以呢"。列出四象限之后，用一句话总结"基于以上，我们决定……"。没有这句总结，分析就还停留在描述层面。

## 怎么用

1. 写清目标与范围。一句话说明这次分析要回答什么问题，比如"判断是否进入某细分市场"。范围定得越具体，后面列因素时越不容易跑题。
2. 列出内部因素。分别写下优势和劣势，尽量用事实和证据支撑，避免"团队氛围好"这类无法验证的描述。
3. 列出外部因素。分别写下机会和威胁，关注政策、技术、需求、竞争格局等外部变化，并标注大致的时间窗口。
4. 给每条因素标权重。用高、中、低表示它对目标的影响程度，再按重要性排序，砍掉不重要的条目。
5. 做组合分析。把优势与机会、劣势与机会、优势与威胁、劣势与威胁配对，分别写出 SO、WO、ST、WT 四类策略。
6. 收敛成行动。从四类策略里挑出优先级最高的两三条，转成有负责人、有期限的具体任务。

落地时有几个小技巧：先各自独立填写再合并，避免讨论被强势的人带偏；对每一条因素追问"凭什么这么说"，逼出证据；如果四类策略太多，就只保留能落到本季度的那几条。

## 示例

以一家做企业培训的中小公司为例，目标是"判断未来一年是否加大线上课程的投入"。

| 象限 | 具体因素 |
| --- | --- |
| 优势 S | 拥有一批合作多年的企业客户；讲师口碑好，复购率高；线下课程交付质量稳定 |
| 劣势 W | 线上课程制作能力弱；缺少产品和技术团队；品牌在个人学员市场知名度低 |
| 机会 O | 企业预算从线下集训转向线上；AI 工具降低了课程制作成本；远程学习需求持续增长 |
| 威胁 T | 线上培训平台竞争激烈；大厂免费内容挤压市场；客户对线上效果仍有疑虑 |

组合之后得到的策略：

| 策略类型 | 组合 | 具体方向 |
| --- | --- | --- |
| SO 进攻 | 优势 + 机会 | 用现有企业客户关系，把线下课程改造成线上混合课，率先试点 |
| WO 扭转 | 劣势 + 机会 | 借助 AI 工具和外部制作团队补齐线上内容能力，不必自建团队 |
| ST 防御 | 优势 + 威胁 | 用口碑和复购率做背书，强调"有人带、有陪伴"的差异化，避开纯内容比价 |
| WT 收缩 | 劣势 + 威胁 | 暂不投入个人学员市场，避免与平台在大众流量上正面竞争 |

从这四类策略里，公司可以收敛出下季度的三个动作：先选三家关系最好的老客户做线上混合课试点；同时用外部团队制作首批课程，验证成本与效果；对外传播时统一强调"陪伴式学习"，与平台的标准内容区隔开。

## 适用场景

- 企业或团队的年度战略规划与复盘
- 新业务、新市场的立项评估
- 产品定位与竞争策略梳理
- 个人的职业选择、技能规划与转型判断
- 投标、竞标前的优劣势盘点
- 项目结束后的事后复盘（Post-mortem）
- 谈判前的立场与筹码分析
- 团队重组或组织调整前的现状评估
- 融资路演前的公司现状梳理
- 关键岗位招聘前的团队盘点
- 竞标方案的针对性设计
- 个人年度目标与能力的匹配评估
- 合作伙伴关系的前景判断
- 转型方向的机会成本分析

## 常见误区

- 只列清单不组合。四个象限填得满满当当，却没有推出任何策略，等于没做分析。
- 内外不分。把"竞争对手很强"这种外部威胁写进劣势，或把"我们团队执行力强"这种内部优势写成机会，破坏了两条轴的意义。
- 形容词代替事实。"管理规范""机制灵活"这类话无法验证，也无法排序。
- 忽略权重。所有因素一视同仁，结果最重要的两三条被淹没在长清单里。
- 一次做完就锁死。SWOT 是快照，外部环境变了就要重做，不能当成长期不变的结论。
- 把 SWOT 当结论。它只是帮你理清处境的中间工具，最终决策还要结合资源、时机和执行能力。
- 只做加法不做减法。列了二十条因素却不肯删，重点被稀释，讨论也无法收敛。
- 单人闭门造车。关键判断缺少相关方参与，结论难以被团队接受和执行。

## 相关工具

- PEST 与 PESTEL 分析：专门用来扫描外部宏观环境，可以给 SWOT 中的机会和威胁提供更系统的输入。
- 波特五力模型：分析行业竞争结构，用来判断 SWOT 里"竞争"相关的外部因素。
- 3C 战略分析：从公司、客户、竞争者三方切入，与 SWOT 的内部视角互补。
- 商业模式画布：SWOT 给出方向后，用画布把战略落到具体的业务模块上。
- 决策矩阵：当 SWOT 推出多条策略难以取舍时，用加权打分选出优先项。
- TOWS 矩阵：SWOT 的组合分析版本，重点在"如何用内部因素应对外部因素"。
- 价值链分析：帮助更细地拆解"优势"和"劣势"究竟来自哪些环节。
