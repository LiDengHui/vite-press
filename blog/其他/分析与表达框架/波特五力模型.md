# 波特五力模型

[[toc]]

波特五力模型是迈克尔·波特提出的行业竞争结构分析框架，用五种力量来判断一个行业的竞争强度和盈利潜力：现有竞争者的竞争、潜在进入者的威胁、替代品的威胁、供应商的议价能力、购买者的议价能力。它解决的是"这个行业到底好不好赚钱、我该不该进、进去后靠什么立足"的问题，是战略咨询和行业研究中最常用的工具之一。

它最大的价值在于把"竞争"从一个笼统的概念拆成了五种可分别评估的力量，让企业能看清利润究竟被谁拿走，以及自己能在哪个环节建立优势。

## 一句话概括

> 一个行业赚不赚钱，不只看对手多不多，还要看新人能不能进、替代品多不多、上下游能不能压你。

换句话说，行业利润不是被单一对手决定的，而是被五股力量共同挤压的结果，战略的任务就是改变这股力量的结构，或者找到对自己有利的位置。

## 核心思想

波特的核心判断是：行业的平均盈利水平，主要不取决于产品本身，而取决于竞争结构。同样做硬件，有的行业长期高毛利，有的行业拼到只剩薄利，差别往往就在这五种力量的强弱上。所以进入一个行业前，先看清结构，比研究产品功能更重要。

五种力量从不同方向挤压利润。现有竞争者通过价格战、广告战、产品迭代争夺份额，对手越多、越势均力敌、退出壁垒越高，竞争越激烈。潜在进入者带来新增产能和新的打法，进入壁垒越低，威胁越大。替代品用另一种方式满足同样的需求，比如视频会议替代部分差旅，它的性价比越高，行业的天花板越低。供应商和购买者则从上下游两端挤压议价空间，当供应集中度高或客户集中度高时，行业利润容易被上下游拿走。

五种力量共同决定了行业的"结构性吸引力"。力量越强，行业越难赚钱；力量越弱，越容易维持超额利润。战略的意义就在于改变结构或者选择位置：要么通过差异化、专利、规模效应抬高进入壁垒，削弱某种力量；要么在一个结构相对友好的细分领域里占据有利位置。

判断每种力量强弱，可以借助几个具体的观察点。看现有竞争，观察行业集中度、产能利用率、产品同质化程度；看进入威胁，观察资金、技术、渠道、政策等壁垒；看替代品，观察替代方案的价格性能和替代速度；看供应商，观察供应商数量、切换成本；看购买者，观察客户集中度和价格敏感度。

这个模型有一个重要局限：它诞生于相对稳定的产业结构中，对平台经济、网络效应、快速迭代的行业解释力会打折。互联网产品往往呈现"赢家通吃"，五力中的进入壁垒和替代逻辑与传统行业不同。所以在这些领域使用时，要结合网络效应、双边市场等新视角，不能生搬硬套。

五种力量并不是孤立的。进入壁垒高往往意味着现有竞争相对缓和，替代品多又会削弱购买者的忠诚，这些力量之间存在联动。分析时把它们放在一起看，才能理解行业结构的整体样貌。

五力还可以用来判断行业演变的方向。当技术降低了进入壁垒，或政策放开了限制，原本稳定的结构会迅速改变。能提前预判这种变化的企业，往往能抢占先机。

不同细分市场的五力结构可能差别很大。一个行业整体竞争激烈，但其中某个细分领域可能因为壁垒高、对手少而利润丰厚。只看行业平均数据，容易错过这样的机会。

对创业公司而言，五力的意义在于选择战场。与其在五力都很强的红海里硬拼，不如找一个某几股力量较弱的细分市场切入，先站稳再扩张。

五力分析也可以反过来用，即评估自己的行为会如何改变行业结构。比如通过专利、生态或规模效应抬高进入壁垒，把不利的结构改造得对自己更有利。

最后，五力的结论要结合自身能力来看。一个结构再好的行业，如果自己缺乏相应能力，也未必能赚到钱。行业吸引力是必要条件，不是充分条件。

## 怎么用

1. 界定行业边界。先说清分析的是哪个行业、哪一层环节，边界模糊会让五种力量无从判断。
2. 逐一评估五种力量。每种力量用高、中、低打分，并写出支撑判断的证据，比如行业集中度、进入壁垒、替代品增速。
3. 找出最强的一两股力量。真正决定行业利润的往往只是一两股力量，聚焦它们比平均用力更有价值。
4. 推导对盈利的影响。判断这些力量会如何压缩利润空间，行业平均毛利大概处于什么水平。
5. 制定应对策略。针对关键力量设计对策，比如用差异化削弱替代品威胁，用后向整合降低供应商议价。
6. 动态跟踪。技术在变、政策在变，力量强弱也会变，建议定期重新评估。

评估时要尽量用可观察的指标，而不是笼统印象。比如"竞争者众多"可以说成"前五名份额不足三成、产品差异小"，这样判断才有说服力，也便于后续复评时对比变化。

## 示例

以国内外卖平台行业为例，用五力做一次结构判断。

| 力量 | 强度 | 判断依据 |
| --- | --- | --- |
| 现有竞争者 | 高 | 头部两家长期贴身竞争，补贴与费率战频繁 |
| 潜在进入者 | 低 | 需要庞大的骑手网络和商户资源，进入壁垒极高 |
| 替代品 | 中 | 到店自取、预制菜、社区团购分流部分场景 |
| 供应商议价 | 中 | 骑手与商户整体分散，但核心商圈优质商户有一定话语权 |
| 购买者议价 | 高 | 消费者对价格和配送费高度敏感，可随时切换平台 |

结论：进入壁垒高，头部格局稳定，但购买者议价能力强、替代品持续分流，意味着平台很难长期维持高毛利，必须靠规模效应和生态协同（如即时零售）寻找新的利润来源。

对应的策略方向也很清楚：面对高强度的同行竞争，靠补贴硬拼不可持续，应转向履约效率和品类扩展；面对强购买者议价，用会员体系和生态绑定提高转换成本；面对替代品，主动把到店、自取等场景纳入自己的服务体系，而不是与替代品对抗。

## 适用场景

- 判断是否进入某个行业或细分市场
- 分析企业当前所处行业的盈利前景
- 投资研究中的行业结构评估
- 制定竞争战略与差异化定位
- 解释为什么某些行业长期低毛利
- 作为 SWOT 与 PEST 之后的结构化补充
- 并购与投资标的的行业地位评估
- 新业务模式的可行性预判
- 供应链上下游议价能力的评估
- 行业进入壁垒的量化分析
- 替代技术对现有业务的影响判断
- 客户集中度带来的风险分析
- 供应商依赖度的风险评估
- 行业整合趋势的预判
- 定价权归属的分析
- 长期利润空间的判断

## 常见误区

- 行业边界不清。把不同环节、不同细分混在一起分析，结论失去意义。
- 只盯现有对手。忽略替代品和上下游的挤压，低估了利润被侵蚀的风险。
- 把力量当成静态。一次分析就当作定论，没有跟踪技术、政策带来的结构变化。
- 混淆"力量强弱"和"企业强弱"。五力描述的是行业结构，不是某家公司的能力。
- 生搬到平台型行业。忽略网络效应、双边市场等特性，得出错误结论。
- 只诊断不开方。分析完五种力量却不给应对策略，等于没做。
- 打分缺证据。凭感觉给高、中、低，结论经不起追问。
- 忽略细分差异。同一行业的不同细分，力量结构可能差别很大，一刀切会失真。

## 相关工具

- PEST 与 PESTEL 分析：看宏观环境，与五力的行业结构视角互为补充。
- SWOT 分析：把五力得出的竞争判断填入威胁与机会象限。
- 3C 战略分析：五力看结构，3C 看公司、客户、竞争者的相对位置。
- 商业模式画布：五力分析后，用画布设计如何重构价值链和盈利模式。
- 价值链分析：波特本人的另一工具，用于拆解企业内部活动以寻找竞争优势。
- 决策矩阵：在多个行业或市场间取舍时，用五力结论作为评分维度。
