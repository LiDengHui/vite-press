# 3C战略分析

[[toc]]

3C 战略分析由大前研一提出，用三个以 C 开头的角色来构建战略思考的三角：公司（Company）、客户（Customer）、竞争者（Competitor）。它解决的是"我凭什么赢、为谁创造价值、对手会不会抢走"这三个必须同时回答的问题。企业制定战略、做业务定位、评估新方向时，用它来确保思考不偏废任何一角。

大前研一长期研究日本企业的国际竞争，他发现成功的战略往往不是宏大规划的结果，而是把客户、竞争者和自身能力想得足够透之后，做出的一两个关键取舍。3C 就是把这个思考过程固化成可操作的三角框架。

## 一句话概括

> 战略必须同时回答三件事：客户要什么、对手给什么、我有什么——三个圆的交集才是立足点。

三个角缺一不可：少一个，战略就会出现明显的漏洞，或自嗨、或跟风、或无从落地。

## 核心思想

大前研一的核心观点是：战略的本质是建立相对优势，而相对优势只存在于"公司、客户、竞争者"三者的关系中。只谈客户需求，容易做出谁都能做的产品；只谈自身能力，容易造出没人要的东西；只谈对手，容易陷入被动模仿。三者必须同时考虑，战略才站得住。

三个 C 各有侧重。公司回答"我有什么独特能力、成本结构如何、资源能支撑什么"，重点是找出别人难以复制的东西。客户回答"谁是我的客户、他们的真实需求和未被满足的痛点是什么、他们如何做选择"，重点是细分和洞察，而不是泛泛的"客户想要更好更便宜"。竞争者回答"对手是谁、他们的战略和优劣势如何、他们会如何反应"，重点是预测而不是描述。

三个圆交叠的部分，才是可持续的战略空间。公司的优势如果能同时满足客户的真实需求、又是竞争者短期难以模仿的，这里就是护城河。反过来，任何一角缺失，战略都会出现漏洞：有优势但客户不买账，是自嗨；客户有需求但谁都能做，会陷入价格战；对手已经占据的位置硬闯，代价高昂。

大前研一还强调战略要"做取舍"。三个 C 分析的目的不是找到所有能做的事，而是决定不做什么。资源有限，把力气集中在三圆交集上，比四处铺开更容易形成优势。

分析三个 C 时，最大的难点在于"客户"这一角。客户说的需求往往不是真实需求，真实需求要靠观察他们的行为和取舍来推断。比如客户说想要更便宜，实际上可能是不愿意为用不上的功能付费。把表层诉求和深层动机分开，是客户分析的关键。

"竞争者"这一角也要避免只看直接对手。真正抢走客户的，可能是完全不同的解决方案，比如客户用"不做"来代替购买。所以竞争者的定义要放宽到"客户用来解决同一问题的所有替代方式"。

最后，3C 不是一次性的静态分析。客户的需求会变、对手的策略会变、自己的能力也会变，所以三圆交集是动态的。好的战略会持续监测这三个角的变化，在交集移动时及时调整定位。

分析三个 C 时，还要警惕"自我中心"的倾向。人对自己的能力往往估计过高，对客户的真实需求又了解不足。所以在做公司这一角时，最好引入外部视角，比如让销售、客服这些直接接触客户的人参与，避免把内部共识当成市场事实。

三个 C 的优先级会随企业发展阶段变化。创业初期，客户和竞争者信息往往不足，重点是把客户需求摸清；成长期，竞争者变得关键，要在同质化竞争中找到差异；成熟期，公司自身的成本和效率成为焦点。认识到这一点，可以让分析更贴合当下最紧迫的问题。

在实践中，3C 常被用来回答一个具体问题，比如"我们的定价是否合理"。这时三个角就变成了三个提问：客户愿意为这个价值付多少钱、对手的定价和成本结构如何、我们自己的成本底线在哪里。把 3C 拆成这类具体问题，比泛泛而谈更容易得到有用的结论。

最后，3C 的结论应该能被检验。一个定位如果只停留在纸面上，就只是愿望。把定位转成可观察的指标，比如目标客户的转化率、复购率、相对对手的价格溢价，才能验证它是否真的成立。

## 怎么用

1. 分析公司自身。列出核心能力、成本结构、品牌、渠道、技术等，找出真正难以被复制的一两项。
2. 细分并分析客户。把客户分成若干群体，分别写清他们的需求、痛点、决策标准和购买习惯。
3. 识别并分析竞争者。列出主要对手，比较他们的定位、优劣势，并推测他们可能的反应。
4. 画三个圆找交集。把三份结论叠在一起，找出公司优势能覆盖客户需求、又避开对手强项的区域。
5. 检验可行性。对交集区域追问：资源够不够、对手会不会跟进、客户愿不愿意付费。
6. 形成战略取舍。把交集收敛成一两句定位，并明确列出"不做什么"。

做客户分析时，可以多问几个"为什么"，从表层诉求追到深层动机；做竞争者分析时，除了对比功能，更要对比他们服务了谁、放弃了谁，这样才看得出交集的空隙在哪里。

## 示例

以一家想进入中小企业财务软件市场的公司为例。

| 维度 | 关键结论 |
| --- | --- |
| 公司 Company | 强项是本地化部署与数据合规经验；弱项是云产品与销售渠道 |
| 客户 Customer | 中小制造企业，最在意数据留在本地、能对接现有财务流程、价格可控 |
| 竞争者 Competitor | 头部云厂商主打标准化 SaaS，价格低但难以满足本地部署与定制需求 |

三圆交集：那些对数据合规和本地部署有硬性要求、又用不起定制开发的中小制造企业。头部厂商的标准化产品覆盖不到，正好落在公司的强项上。战略定位可以定为"面向中小制造企业的合规型本地财务系统"，并明确不做大众化的低价云版。

把取舍写清楚，可以帮助团队聚焦：

| 要做 | 不做 |
| --- | --- |
| 面向中小制造企业的本地化合规部署 | 面向所有中小企业的通用云 SaaS |
| 对接主流财务与进销存系统 | 自建全套 ERP 功能 |
| 用行业顾问做深度服务 | 纯线上自助、无人工支持的低价路线 |

## 适用场景

- 制定业务战略与市场定位
- 判断新方向是否值得投入
- 进入新市场前的定位分析
- 品牌与差异化策略梳理
- 创业项目的早期战略思考
- 与 SWOT、五力配合构成完整的外部与内部视角
- 产品线取舍与资源聚焦
- 面向投资人的战略陈述准备
- 定价策略的制定与调整
- 合作伙伴与渠道的选择
- 年度经营计划的目标对齐
- 竞品动态下的应对策略讨论
- 新产品的市场切入方式设计
- 组织能力与业务方向的匹配评估

## 常见误区

- 三角失衡。只分析其中一两个 C，尤其是只研究客户和对手，忘了审视自身能力。
- 客户分析太笼统。不细分、不洞察，把"客户想要更好"当成需求。
- 静态看对手。假设对手不会反应，低估了跟进和反击的可能。
- 找不到交集就硬上。三圆没有重叠仍强行推进，等于用短板去拼对手强项。
- 只做加法不做减法。列出很多可做之事，却不明确取舍，战略等于没有重点。
- 把 3C 当竞品调研。它本质是战略思考框架，不是简单的竞品功能对比表。
- 忽视客户行为。只听客户怎么说，不看客户实际怎么选，容易误判需求。
- 竞争者定义过窄。只盯直接对手，忽略替代方案和"不消费"这种选择。

## 相关工具

- SWOT 分析：3C 中的公司与竞争者分析，可以对应到 SWOT 的优势劣势与威胁。
- 波特五力模型：五力看行业结构，3C 看三方关系，两者互补。
- PEST 与 PESTEL 分析：为 3C 的客户与竞争者分析提供宏观背景。
- 商业模式画布：把 3C 得出的定位落到具体的业务模块设计上。
- 价值链分析：帮助深入拆解"公司"这一角的能力构成。
- 价值主张画布：深入打磨"客户"与"公司"两角的匹配关系。
- 决策矩阵：在多个候选定位之间做量化比较。
