# 非暴力沟通

[[toc]]

非暴力沟通由马歇尔·卢森堡提出，是一套在对话中减少对抗、增进理解的沟通方法，包含四个要素：观察、感受、需要、请求。它解决的是"想表达不满或需求，又不想激化矛盾"的问题。处理亲密关系、团队冲突、客户投诉、跨部门协作时，它提供了一种把指责转成表达的语言方式。

卢森堡长期从事冲突调解，他发现很多冲突并非源于利益对立，而是源于语言中隐含的评判和指责。非暴力沟通的目标，是让人把注意力从"谁对谁错"转向"彼此的需要是什么"。

## 一句话概括

> 说清你观察到的事实、你的感受、背后的需要，再提出一个具体的请求，而不是指责对方。

四要素的顺序很关键：先描述事实，再表达感受，然后说出需要，最后提出请求，避免一开口就评判。

## 核心思想

非暴力沟通的第一要素是"观察"，也就是不带评判地描述事实。区分观察和评判是这个方法最难、也最关键的一步。"你总是迟到"是评判，"这周你有三次会议迟到了十分钟"是观察。评判容易引发辩解和反击，而具体的事实则更容易被双方接受。

第二要素是"感受"。很多人习惯说"我觉得你不尊重我"，这其实是评判而不是感受。真正的感受是"我感到失望""我感到着急"。把感受和评判分开，能让对方更容易理解你的状态，而不是立刻进入防御。

第三要素是"需要"。感受往往来自未被满足的需要，比如被忽视对应着被尊重的需要，焦虑对应着确定性的需要。把感受背后的需要说出来，对方才知道真正要解决的问题是什么，而不是停留在表面的情绪对抗。

第四要素是"请求"。请求要具体、可执行，并且是"要什么"而不是"不要什么"。"我希望你以后别再这样"是模糊的指责；"我希望下次会议前你能提前一天把材料发给我"是具体请求。请求和命令的区别在于，对方有拒绝的空间，这才叫请求。

把四要素串起来，一段典型的表达是："我注意到（观察）……我感到（感受）……因为我需要（需要）……你愿意（请求）吗？"这个句式不一定要逐字使用，但四个要素最好都在，缺了哪一个，表达就容易退回到指责或抱怨。

非暴力沟通不仅用于表达，也用于倾听。当对方情绪激动时，先努力听出他的观察、感受、需要和请求，而不是急于反驳。听懂了需要，很多看似激烈的对话会迅速降温。

这个方法的核心前提是：人的行为背后都有需要，冲突往往是需要未被看见。它不承诺让对方一定答应你的请求，但能显著降低对抗，为解决问题创造条件。

需要提醒的是，非暴力沟通不是软弱或忍让。它要求你清晰、坚定地表达自己的需要，只是把方式从指责换成了陈述。这需要练习，尤其是在情绪上头的时候。

非暴力沟通的前提是同理心。它假设对方的行为背后也有未被满足的需要，而不是单纯的恶意。带着这个前提去对话，语气和用词都会自然改变。

在实践中，四要素不一定要全部说出。有时只需描述观察和表达感受，对方就能理解；有时对方情绪激动，先倾听他的需要比急着表达自己更有效。关键是根据情境灵活运用。

非暴力沟通也适用于自我对话。当自己情绪低落时，用四要素梳理：发生了什么、我有什么感受、我需要什么、我可以为自己做什么。这能帮助人从情绪中抽离出来，看清真正的需要。

最后，非暴力沟通需要长期练习。它的难点不在记住四要素，而在于情绪上头时仍能保持觉察。从低风险的小事练起，慢慢把它变成习惯，才能在关键时刻用得上。

## 怎么用

1. 描述观察。只说你看到、听到的事实，去掉"总是""从不""你这个人"这类评判词。
2. 表达感受。用"我感到……"说出自己的真实情绪，而不是用"你让我……"把责任推给对方。
3. 说出需要。说明感受背后未被满足的需要，比如被尊重、被理解、有确定性。
4. 提出请求。给出具体、可执行、可被拒绝的请求，而不是模糊的要求或命令。
5. 倾听对方。用同样的四要素去理解对方的表达，先听懂需要再回应。
6. 反复练习。从低风险的对话开始练习，逐渐用到情绪更强的场合。

在开口前，可以先在心里把想说的话过一遍：这句话里有没有评判？我的感受是什么？我真正需要什么？我想要对方做的具体行为是什么？

## 示例

以同事反复拖延影响项目进度为例，对比两种表达。

| 方式 | 表达 |
| --- | --- |
| 暴力沟通 | 你怎么又拖到最后一刻，一点都不负责任，整个项目都被你耽误了 |
| 非暴力沟通 | 这次的文档比约定时间晚了两天交付（观察），我有点着急（感受），因为后面的测试需要它才能开始（需要），下次能不能在约定日期的前一天先给我一个初稿（请求） |

再以家庭场景为例：

| 要素 | 内容 |
| --- | --- |
| 观察 | 这周有三个晚上你都在加班到十点以后才回家 |
| 感受 | 我感到有些孤单，也有点担心你的身体 |
| 需要 | 我希望我们能有一些一起吃饭的时间 |
| 请求 | 这周末能不能留一个晚上我们一起吃顿饭 |

两段表达都没有指责，却把事实、情绪和需求讲得清清楚楚，对方更容易回应，而不是反驳。

- 亲密关系与家庭沟通
- 团队内部的冲突调解
- 跨部门协作中的分歧处理
- 客户投诉与售后沟通
- 管理者给出负面反馈
- 谈判中的需求表达
- 教育与亲子沟通
- 自我觉察与情绪管理
- 向同事提出不同意见

- 合租与邻里关系的沟通

- 网络讨论中的理性表达
- 自我情绪的日常梳理

## 常见误区

- 把评判当观察。"你总是……""你从不……"本质是评判，容易引发对抗。
- 把想法当感受。说"我觉得被忽视"其实是判断，不是感受。
- 跳过需要直接提要求。对方不知道你真正在意什么，请求显得突兀。
- 请求太模糊。"你对我好一点"无法执行，对方无从下手。
- 把请求当命令。不留拒绝空间，对方感到被强迫。
- 只在表达时用，倾听时不用。忽略对方的四要素，对话仍会僵持。
- 把方法当软弱。以为非暴力就是忍让，其实它要求坚定表达需要。
- 情绪上头时硬套句式。带着怒气说模板话，反而显得讽刺。
