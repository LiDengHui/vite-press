# 商业模式画布

[[toc]]

商业模式画布由亚历山大·奥斯特瓦德提出，是一种用九个模块把一门生意的运作方式画在一张纸上的工具。它解决的是"这门生意到底靠什么运转、钱从哪里来、成本花在哪里"的问题，让团队能用统一的语言快速描述、比较和改进商业模式。创业团队做早期规划、大公司做新业务设计、投资人做项目评估时都常用它。

奥斯特瓦德在研究中比较了大量商业模式，发现无论行业和规模，一门生意都可以拆解成同样九个关键问题。把这九个问题画成一页纸，就得到了这张可以反复涂改的"草稿纸"。

## 一句话概括

> 用九个格子回答：为谁、提供什么、怎么触达、怎么赚钱、花在哪里、靠什么支撑。

它的精髓不在填写，而在于让九个格子互相印证，把商业模式的漏洞暴露在一页纸上。

## 核心思想

画布的价值在于把商业模式结构化。传统商业计划书写几十页才能说清的事，画布用九个模块强迫你在同一页里把逻辑对齐。九个模块彼此关联，任何一个改动都会牵动其他模块，这让"假设—验证"的循环变得更快。

九个模块可以分为四组。供给端：关键伙伴、关键活动、关键资源，说明这门生意靠什么运转。需求端：客户细分、客户关系、渠道通路，说明价值交付给谁、怎么交付。价值主张处在中间，是连接供需的核心，回答"我们为客户解决什么问题、提供什么独特价值"。财务：收入来源和成本结构，说明钱怎么进来、怎么花出去。

画布最重要的用法不是"填写"，而是让九个模块相互印证。价值主张必须匹配客户细分的真实需求，渠道通路必须触达这些客户，收入来源必须与客户的付费意愿一致，成本结构必须与关键活动相匹配。任何一个模块与其他模块对不上，商业模式就有裂缝。

奥斯特瓦德后来把画布扩展成"价值主张画布"，专门用来深入匹配客户痛点与产品价值。在实际操作中，通常先用画布画出整体，再用价值主张画布打磨最核心的那一格。

画布也适合反复迭代：先画一个粗版假设，再通过访谈、试验去验证和修正，而不是一次画完就定稿。它天然适合配合精益创业的思路，把每个模块都当作待验证的假设。

需要提醒的是，画布描述的是"逻辑"，不是"数据"。它不告诉你收入会有多少、成本会是多少，只帮你检查这些数字背后的逻辑是否成立。真正的财务测算要靠另外的工具，但逻辑不清的财务预测往往是空中楼阁。

最后，画布也是团队对齐的工具。把九个格子挂在墙上，让不同岗位的人各自认领自己的格子，分歧会立刻显形：销售理解的客户和产品理解的客户可能完全不同，这种分歧越早暴露越好。

画布也常被用来做竞品对比。把竞争对手的商业模式也画成一张画布，两相对照，就能看出彼此在客户细分、价值主张和收入来源上的差异。这种对比比单纯比较功能更能揭示竞争的本质。

在使用画布时，要注意区分"现在的模式"和"想要的模式"。前者描述现状，后者描述目标。两张画布并排放，中间就是需要完成的转变，也就能据此规划路径和资源。

画布对成熟企业同样有用。很多公司对自己的商业模式习以为常，反而说不清楚。用画布把它显性化，往往能发现被忽略的模块，比如客户关系维护长期缺失，或成本结构里有一块没人负责。

最后，画布的价值在讨论中体现。一个人填画布只是自问自答，一群人填画布则会暴露认知差异。把画布当作讨论的媒介，而不是汇报的成品，才能发挥它对齐认知的作用。

## 怎么用

1. 先填客户细分。明确到底服务哪几类人，避免"所有需要的人"这种模糊描述。
2. 写价值主张。针对每类客户，说明你为他们解决什么痛点、带来什么收益。
3. 设计渠道与客户关系。说明客户如何知道、如何购买、如何获得服务与留存。
4. 梳理收入来源。写清收费方式（一次性、订阅、抽成等）和定价逻辑。
5. 列出关键资源、关键活动、关键伙伴。说明支撑这门生意所需的资产、必须做好的事和外部依赖。
6. 核算成本结构。把主要成本项列出来，判断是成本驱动还是价值驱动。
7. 检查一致性并迭代。逐格检查逻辑是否自洽，找出最不确定的假设优先验证。

填写顺序建议从右往左、从客户出发，再回到左半边的资源和成本。这样能避免先想"我们有什么"而忽略客户真正要什么。

## 示例

以一款面向自由职业者的发票与报税工具为例，九个模块如下。

| 模块 | 内容 |
| --- | --- |
| 客户细分 | 个人自由职业者、小微工作室主理人 |
| 价值主张 | 几分钟开出发票、自动汇总收入、报税季一键生成报表 |
| 渠道通路 | 应用商店、财税类内容社区、老用户推荐 |
| 客户关系 | 自助式使用 + 邮件与在线客服支持 |
| 收入来源 | 免费基础版 + 高级版月订阅 + 增值报税服务 |
| 关键资源 | 产品与工程团队、税务规则数据库、品牌口碑 |
| 关键活动 | 产品迭代、税务规则更新、内容运营 |
| 关键伙伴 | 支付通道、电子发票服务商、财税顾问 |
| 成本结构 | 研发与服务器成本为主，客服与合规成本次之 |

检查一致性：客户对价格敏感，所以用免费版获客、订阅制变现；税务规则复杂度高，因此需要关键伙伴提供专业支持，成本结构也以研发与合规为主。整体逻辑自洽。

进一步把最不确定的假设标出来，可以排出一个验证清单：

| 假设 | 验证方式 |
| --- | --- |
| 自由职业者愿意为自动报税付费 | 上线订阅版，观察付费转化 |
| 内容社区能带来低成本获客 | 投放一批内容，测量获客成本 |
| 税务规则可维护且成本可控 | 先覆盖一个地区，评估更新工作量 |

## 常见误区

- 只填格子不检查一致性。九格填满却互相矛盾，画布变成装饰。
- 把画布当商业计划书。画布是思考工具，不能替代详细的财务与执行计划。
- 价值主张自说自话。写的是自己觉得好，而不是客户真正在意的痛点。
- 客户细分太宽。想服务所有人，结果价值主张无法聚焦。
- 忽略成本结构。只算收入不算成本，商业模式看似美好却不可持续。
- 画完就锁死。不通过试验验证假设，把假设当事实。
- 忽略模块联动。改了一个格子却不检查对其他格子的影响。
- 缺少外部输入。闭门填写，没有客户访谈和行业数据的支撑。

## 相关工具

- 价值主张画布：画布的配套工具，专门深入匹配客户痛点与产品价值。
- SWOT 分析：为画布中的关键资源和外部环境提供输入。
- 3C 战略分析：帮助理清客户细分与竞争定位。
- 波特五力模型：判断画布所处的行业结构是否有利可图。
- 精益创业与最小可行产品：用最小成本验证画布中的关键假设。
- PEST 与 PESTEL 分析：为画布的外部环境判断提供宏观输入。
- 决策矩阵：在多个商业模式方案之间做量化比较。
