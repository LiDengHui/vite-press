# 响应式与媒体查询

媒体查询（Media Queries）是响应式设计的核心，让页面能够根据设备特性自适应展示。

---

## 一、基本语法

```css
/* 基本结构 */
@media media-type and (media-feature) {
    /* 样式 */
}

/* 常见写法 */
@media screen and (max-width: 768px) {
    body { font-size: 14px; }
}

/* 多条件 */
@media screen and (min-width: 768px) and (max-width: 1024px) {
    /* 平板 */
}

/* 或条件 */
@media (max-width: 768px), (min-width: 1920px) {
    /* 手机 或 超大屏 */
}

/* 非 */
@media not print {
    /* 非打印模式 */
}
```

### 媒体类型

```css
all       /* 所有设备（默认） */
screen    /* 屏幕 */
print     /* 打印 */
speech    /* 屏幕阅读器 */
```

### 常用媒体特性

```css
width / min-width / max-width       /* 视口宽度 */
height / min-height / max-height    /* 视口高度 */
aspect-ratio                        /* 宽高比 */
orientation                         /* 方向：portrait/landscape */
hover                               /* 指针能否悬停 */
pointer                             /* 指针精度：none/coarse/fine */
prefers-color-scheme                /* 深色/浅色模式 */
prefers-reduced-motion              /* 是否减少动画 */
```

## 二、断点设计

### 经典断点

```css
/* 手机 */
@media (max-width: 767px) { }

/* 平板 */
@media (min-width: 768px) and (max-width: 1023px) { }

/* 桌面 */
@media (min-width: 1024px) { }

/* 大屏 */
@media (min-width: 1440px) { }
```

### 现代断点（基于内容）

```css
/* 不需要固定断点，按内容决定 */
.container {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
}
```

### CSS 变量管理断点

```css
:root {
    --bp-sm: 576px;
    --bp-md: 768px;
    --bp-lg: 1024px;
    --bp-xl: 1440px;
}
```

> 注意：CSS 变量不能在媒体查询条件中直接使用，但可用于样式值。

## 三、容器查询（Container Queries）

容器查询是媒体查询的进化版，基于**容器尺寸**而非视口尺寸。

```css
/* 1. 声明容器 */
.card-wrapper {
    container-type: inline-size;  /* 基于宽度 */
    container-name: card;         /* 命名容器 */
}

/* 2. 容器查询 */
@container (min-width: 400px) {
    .card {
        display: flex;
        flex-direction: row;
    }
}

/* 3. 命名容器查询 */
@container card (min-width: 600px) {
    .card { font-size: 18px; }
}
```

### 容器查询单位

```css
@container (min-width: 400px) {
    .card-title {
        font-size: 5cqw;  /* 容器宽度的 5% */
        padding: 2cqi;    /* 容器内联尺寸的 2% */
    }
}
```

| 单位 | 说明 |
|------|------|
| `cqw` | 容器查询宽度 1% |
| `cqh` | 容器查询高度 1% |
| `cqi` | 容器内联尺寸 1% |
| `cqb` | 容器块级尺寸 1% |
| `cqmin` / `cqmax` | 容器最小/最大尺寸的 1% |

## 四、响应式图片

```html
<!-- 根据设备像素比和宽度选择图片 -->
<img
    srcset="small.jpg 480w, medium.jpg 800w, large.jpg 1200w"
    sizes="(max-width: 600px) 480px, (max-width: 1000px) 800px, 1200px"
    src="fallback.jpg"
    alt="描述"
/>

<!-- 根据设备特性选择不同格式的图片 -->
<picture>
    <source srcset="image.avif" type="image/avif">
    <source srcset="image.webp" type="image/webp">
    <img src="image.jpg" alt="描述">
</picture>
```

## 五、奇淫技巧

### 技巧 1：CSS 逻辑属性

```css
/* 逻辑属性自动适配 LTR/RTL */
.start { margin-inline-start: 20px; }   /* LTR=左，RTL=右 */
.end   { margin-inline-end: 20px; }
.block { padding-block: 16px; }          /* 上下 */
.inline { padding-inline: 24px; }        /* 左右 */

/* 对应传统写法： */
/* margin-left / margin-right 在 RTL 中需要重写 */
```

### 技巧 2： prefers-reduced-motion

```css
/* 尊重用户"减少动画"偏好 */
@media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
        animation-duration: 0.01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: 0.01ms !important;
    }
}
```

### 技巧 3： prefers-color-scheme

```css
/* 跟随系统深色模式 */
@media (prefers-color-scheme: dark) {
    :root {
        --bg: #1a1a1a;
        --text: #e0e0e0;
    }
}
```

### 技巧 4：悬停能力检测

```css
/* 仅对支持悬停的设备应用 hover 样式 */
@media (hover: hover) and (pointer: fine) {
    .btn:hover {
        background: #0056b3;
    }
}

/* 触控设备 */
@media (hover: none) and (pointer: coarse) {
    .btn {
        min-height: 44px;  /* 最小触控区域 */
        min-width: 44px;
    }
}
```

### 技巧 5：响应式排版（clamp）

```css
/* 字体在 16px ~ 24px 之间随视口变化 */
h1 {
    font-size: clamp(1.5rem, 4vw + 1rem, 3rem);
}

/* 容器宽度自适应 */
.container {
    width: clamp(300px, 80%, 1200px);
    margin: 0 auto;
}
```

### 技巧 6：移动端 1px 边框

```css
/* 设备像素比 >= 2 时的 0.5px 边框 */
@media (-webkit-min-device-pixel-ratio: 2) {
    .border-1px {
        position: relative;
    }
    .border-1px::after {
        content: '';
        position: absolute;
        inset: 0;
        border: 1px solid #ccc;
        transform: scale(0.5);
        transform-origin: 0 0;
        width: 200%;
        height: 200%;
        pointer-events: none;
    }
}
```

### 技巧 7：打印样式

```css
@media print {
    /* 隐藏不需要打印的元素 */
    nav, .sidebar, .ads, button { display: none !important; }

    /* 确保背景色打印 */
    * { -webkit-print-color-adjust: exact; print-color-adjust: exact; }

    /* 分页控制 */
    h2 { page-break-before: always; }
    tr { page-break-inside: avoid; }
}
```

### 技巧 8：范围语法（现代写法）

```css
/* 旧写法 */
@media (min-width: 768px) and (max-width: 1023px) { }

/* 新写法（CSS Media Queries Level 4） */
@media (768px <= width < 1024px) { }
```

### 技巧 9：容器查询实现卡片自适应

```css
.product-grid {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
    gap: 16px;
}

.product-card {
    container-type: inline-size;
}

@container (min-width: 350px) {
    .product-card {
        display: flex;
        gap: 16px;
    }
    .product-card img {
        width: 120px;
        flex-shrink: 0;
    }
}

@container (min-width: 500px) {
    .product-card img {
        width: 200px;
    }
}
```

> 💡 **响应式原则**：先写移动端样式，再用 `min-width` 渐进增强。容器查询解决组件级响应式，媒体查询解决页面级响应式。
