## 奇淫技巧

### 技巧 1：纯 CSS 星级评分（完整版）

```html
<div class="stars">
    <input type="radio" name="star" id="s5"><label for="s5">★</label>
    <input type="radio" name="star" id="s4"><label for="s4">★</label>
    <input type="radio" name="star" id="s3"><label for="s3">★</label>
    <input type="radio" name="star" id="s2"><label for="s2">★</label>
    <input type="radio" name="star" id="s1"><label for="s1">★</label>
</div>
```

```css
.stars {
    display: flex;
    flex-flow: row-reverse;
    justify-content: flex-end;
}
.stars input { display: none; }
.stars label {
    font-size: 2rem;
    color: #ccc;
    cursor: pointer;
    transition: color 0.2s;
}
/* 选中当前及之前所有兄弟 */
.stars input:checked ~ label,
.stars label:hover,
.stars label:hover ~ label {
    color: #ffcc00;
}
```

### 技巧 2：半星评分

```css
.stars label {
    position: relative;
}
.stars label::after {
    content: '★';
    position: absolute;
    left: 0; top: 0;
    width: 50%;
    overflow: hidden;
    color: #ffcc00;
    display: none;
}
.stars input.half:checked ~ label::after {
    display: block;
}
```

### 技巧 3：动态颜色渐变

```css
.stars label {
    background: linear-gradient(to right, #ffcc00, #ff9900);
    -webkit-background-clip: text;
    -webkit-text-fill-color: transparent;
}
```
